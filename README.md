# 🌦️ WeatherX

A modern, responsive weather application built with HTML, CSS and JavaScript.

WeatherX uses real-time weather data from the OpenWeather API and provides current weather information, forecasts, location-based weather and recent search history.

## ✨ Features

- 🔍 Search weather by city
- 🌡️ Real-time temperature
- 💧 Humidity information
- 💨 Wind speed
- 🌡️ Atmospheric pressure
- 👁️ Visibility
- 🌅 Sunrise and sunset
- 📅 5-day weather forecast
- 📍 Current location weather
- 💾 Recent search history
- ❌ Error handling
- ⏳ Loading state
- 🌦️ Dynamic weather-based background
- ✨ Smooth animations
- 📱 Responsive design for mobile, tablet and desktop
